# Wash The Dishes: A Dishwashing Simulator 

## What is it?
As part of an undergraduate research project, //Wash the Dishes// is an example of queer game design which subverts expectation, a game that isn’t made to be just for fun, but aims to create a reflective experience for the player. My goal with this project is to evoke frustration, unfairness, or boredom, feelings that are not traditionally associated with having fun, and to break down traditional ideals of the “perfect player” and what a “good game” has to be. This research explores how video games can be used as tools to explore and reflect on how we feel.

Throughout making this game, I used this repository's commit notes to closely document my “no fun” design choices and keep a reflective journal, prioritizing the recoverability of the design process over the product. Working against standard game design paradigms, my commit notes are detailed and explain the thoughts behind each change so that my documentation addresses both the “how” and “why” I designed this game.

There is a hegemonic structure to how games are played and studied that is not inclusive. By disrupting this structure, there is an inherent queerness (challenging the norm and status quo). Studying this queerness can lead to more creative freedoms and experimentation in the industry.

Through the creation, reflection, and research of this demo, I am testing theories about how games can be made, and how a queer approach to game design can effect how a game is created.
